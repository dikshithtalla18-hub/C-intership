# Basic Calculator (C++)

## Project Description

A menu-driven console calculator written in C++ that performs standard
arithmetic operations with input validation and error handling.

## Features

-   Addition
-   Subtraction
-   Multiplication
-   Division (checks division by zero)
-   Modulus (checks modulus by zero)
-   Menu loop until Exit

## Sample Output

The attached screenshots demonstrate: 1. Addition 2. Subtraction 3.
Multiplication 4. Division 5. Modulus 6. Exit

## Requirements

-   C++ compiler (g++, Code::Blocks, VS Code, Dev-C++)

## How to Run

``` bash
g++ calculator.cpp -o calculator
./calculator
```
